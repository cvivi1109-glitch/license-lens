## 3. 兼容性判定（三条关键路径）

```powershell
python -m license_lens check MIT GPL-3.0
```

```
✅ [允许] 上游 MIT  →  我的项目 GPL-3.0（dynamic）
   依据：MIT 属于宽松许可，允许被用于以 GPL-3.0 发布的项目。
   提示：仍需履行 MIT 的义务：保留版权声明与许可声明（复制别人代码时不得删除）；在仓库根目录提供完整 LICENSE 文本
```

```powershell
python -m license_lens check GPL-3.0 MIT
```

```
❌ [禁止] 上游 GPL-3.0  →  我的项目 MIT（dynamic）
   依据：GPL-3.0 具有强传染性，衍生作品必须同样开源；以 MIT 发布违反了这一义务。
   提示：改法一：把项目许可改为 GPL-3.0。
   提示：改法二：换掉该依赖（或改用 LGPL / MIT 的等价库）。
   提示：若只是通过网络调用该库所在的服务（未链接代码），通常不构成衍生作品，但仍需人工确认。
```

```powershell
python -m license_lens check LGPL-3.0 MIT --linkage static
```

```
❌ [禁止] 上游 LGPL-3.0  →  我的项目 MIT（static）
   依据：静态链接 LGPL-3.0 会使你的程序成为衍生作品，而以 MIT 发布无法满足「衍生作品同样开源」的要求。
   提示：改法一：改用动态链接（本工具判定为「允许」）。
   提示：改法二：把项目许可改为 LGPL-3.0 或 GPL-3.0。
   提示：改法三：换掉这个依赖。
```
